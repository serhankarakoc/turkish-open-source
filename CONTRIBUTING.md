# Contributing

Thank you for helping improve the Turkish open-source catalog.

This repository is **not** a hand-curated Awesome List. Discovery, scoring, and README generation are automated. Human review still matters: community verification is preferred when the heuristics are uncertain.

Please read:

- [Contribution guide](docs/CONTRIBUTING.md)
- [Inclusion criteria](docs/CRITERIA.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Scanner / API notes](docs/API.md)

## Rules of thumb

- Do not submit spam, placeholders, or fake projects.
- Do not submit proprietary software.
- A public GitHub repository is not automatically open source. A recognized license is required when `require_license` is enabled.
- Do not add the same repository twice. The unique key is the GitHub repository **ID**, not the name.
- Maintainers may reject projects that fail Turkey-scoring, licensing, activity, or quality checks.
- Automated Turkey detection is **heuristic**. It is not a legal, governmental, or official certification.
- Never edit the generated README block between `<!-- GENERATED:START -->` and `<!-- GENERATED:END -->`. Change `data/projects.json` or the generator instead.

To suggest a project, open an [Add Project](https://github.com/serhankarakoc/turkish-open-source/issues/new?template=add-project.yml) issue.
